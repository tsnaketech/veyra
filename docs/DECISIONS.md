# Décisions

Journal des choix durables : stack, stockage, authentification, dépendances
structurantes ou compromis. Conserver les décisions remplacées et les relier à leur
successeur. Les détails courants d'implémentation n'ont pas besoin d'une entrée.

Aucune décision consignée.

## Modèle

```markdown
## D001 — Titre de la décision

- Date : AAAA-MM-JJ
- Statut : proposée | acceptée | remplacée
- Contexte :
- Options envisagées :
- Décision et justification :
- Conséquences :
- Remplacée par : si applicable
```
